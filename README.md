# Risk-Index-Prediction

국가개발연구과제 "신종 감염병 해외 유입 예측 및  지능적 차단 기술 개발"에서 진행한 자연어 처리 모듈 및 머신러닝 분류모델 기반의 학습 및 추론과정을 정리한 코드입니다.

연구 성과
1. 다국어 뉴스에서 추출한 식별적 색인어 기반 감염병 위험지수 예측, 대한전자공학회, Review 중, 2025
2. Prediction of Increase in COVID-19 Confirmed Cases Through Multilingual Keyword Extraction, The 8th International Conference on Consumer Electronics Asia(ICCE-Asia), Oct 2023.
